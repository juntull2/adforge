# 🚀 AdForge (adforge)

**CapCut + AI TTS 기반의 숏폼/네이버 클립 광고 마케팅 영상 자동화 툴**

AdForge는 마케팅 대본을 입력하면 **AI 성우 더빙(TTS)과 자막, 컷 타임라인**을 자동으로 생성하여 **CapCut 프로젝트 초안(.draft)**으로 변환해 주는 자동화 툴입니다.

---

## 🌟 주요 기능 (Key Features)

- **AI 더빙 음성 자동 생성**: Edge-TTS를 연동하여 고품질 한국어 성우(여성/남성) 음성 MP3 자동 생성
- **1:1 자막-음성 타임라인 싱크**: 음성의 길이를 밀리초 단위로 측정하여 자막 타임라인 자동 동기화
- **CapCut 프로젝트 초안 자동 생성**: 별도의 편집 과정 없이 CapCut 앱에서 바로 열어볼 수 있는 초안 프로젝트 생성
- **네이버 클립 / 숏폼 / 릴스 규격 최적화**: 1080x1920 세로 숏폼 규격 및 가독성 높은 자막 스타일 기본 제공

## 🚀 사용 방법 (Usage)

### A급 소재 찾기와 연결 계정 추적

**🏆 A급 소재 탐색** 탭에서 검색어를 넣고 **A급 소재 찾기**를 누릅니다. 아래 세 가지를 모두 충족하는 광고를 브랜드별로 묶어 보여줍니다.

1. 최근 1년 안에 브랜드(또는 제품) 키워드의 30일 검색량 1만 건 이상인 이력과 직전 60일 대비 60일 증가폭 7천 건 이상인 이력이 있다. 네이버 검색광고 API의 최근 30일 실측 검색수에 데이터랩 일간 추이를 맞춰, 끝나는 날마다 직전 60일 검색량을 계산합니다(달력 월로 자르지 않음). 추이가 없으면 급상승 이력을 확인할 수 없어 확인 불가로 표시합니다.
2. 메타 광고 라이브러리에서 60일 이상 게재 중이다.
3. 광고 문구·페이지명·랜딩 주소에 제품 연관 키워드(기본: 여드름, 트러블, 피지, 영양제 등)가 있고 제외 키워드(반려동물 등)가 없다.

결과는 A급 → 급상승 등급 → 60일 증가폭 순으로 정렬합니다. 동일한 키워드에서 최근 1년의 30일 검색량 1만 건 이상 이력과 60일 증가폭 7천 건 이상 이력을 확인합니다. 증가폭은 각 60일 구간을 바로 앞 60일과 비교합니다. 배수는 A급 필수 조건이 아닙니다.

- 🚀 급상승: 60일 증가폭 7,000건 이상 그리고 직전 60일의 3배 이상 (탐색 조건에서 기준 조정)
- 📈 상승: 증가폭이 기준의 절반 이상이거나 1.5배 이상
- ➖ 꾸준: 그 밖

브랜드 카드에는 "3,100 → 10,200 (+7,100, 3.3배) · 5/4~7/2 · 평소 2,900"처럼 60일 급상승 구간과 평소 수준(그 전 60일 검색량의 중앙값)을 보여주고, 60일 검색량 그래프에 그 구간을 표시합니다. 검색수 상위 키워드 2개까지 추이를 확인합니다. 같은 소재의 변형 광고(메타 묶음 ID가 같은 광고)는 하나로 합쳐 "변형 N개"로 보여줍니다.

브랜드는 페이지 이름이 아니라 광고가 보내는 자사몰 도메인(스마트스토어는 상점 주소)으로 묶습니다. 브랜드명은 자사몰의 사이트 이름에서 읽습니다. 브랜드명 검색량이 낮고 제품명 검색량이 높은 경우처럼 ① 판정 키워드가 맞지 않으면 브랜드마다 키워드를 고쳐 다시 확인할 수 있습니다.

A급 브랜드는 자사몰 도메인·브랜드명·제품명·같은 광고 문구로 광고 라이브러리를 다시 검색해, 같은 자사몰로 광고를 보내는 페이지를 찾습니다. 확인된 숨은·위장·아랍어·외국어 계정은 계정 이름과 광고 문구로 다시 검색합니다(최대 2단계, 브랜드당 추가 검색 24회). 찾은 계정은 🔁와 "찾은 경로"로 표시하고, 페이지 ID로 계정당 기본 최대 20페이지까지 게재 중 광고를 수집합니다. 추가 광고도 같은 랜딩·최소 게재 기간·제품 연관성·제외 키워드를 검사해 통과한 소재를 소재 표·CSV·노션 저장 후보에 합칩니다. 같은 광고 ID와 묶음 ID는 중복으로 늘리지 않으며, 계정별 샘플 5개 제한은 미리보기에만 적용합니다. 페이지 제한·검색 실패·요청 한도 때문에 중단되면 부분 수집 상태를 표시하고 이미 찾은 계정과 소재를 유지합니다. 계정은 아랍어·외국어·위장·숨은·공식 계정으로 분류하고 단축 주소는 최종 주소로 풀어 비교합니다. 결과는 `outputs/a_grade/`에 JSON으로 저장되고 CSV로 내려받을 수 있습니다. 기존 결과는 연결 계정 다시 추적으로 소재를 보충할 수 있습니다.

브랜드마다 ① 판정 키워드의 네이버 검색량(최근 30일, PC·모바일)과 연령·성별층 그래프를 보여줍니다. 연령·성별은 네이버 쇼핑인사이트의 키워드 클릭 비중(식품·화장품/미용·생활/건강 중 데이터가 가장 많은 분류)입니다. 데이터랩 검색어 트렌드는 성별·연령 조건마다 최고점을 100으로 따로 맞춰 주기 때문에 조건끼리 비교해 비중을 낼 수 없습니다.

### 노션 기록 (🏢 브랜드 표 + 🎬 소재 표)

탭 아래 **노션에 기록**에서 A급 브랜드의 광고를 골라 **노션에 저장하기**를 누르면 🎬 소재 표에 저장하고 🏢 브랜드 표의 행을 만들거나 갱신합니다. 브랜드는 `브랜드 키`(자사몰 도메인 등)로, 소재는 `광고 ID`로 찾기 때문에 다시 저장해도 행이 늘지 않습니다. `GOOGLE_DRIVE_FOLDER_URL`이 연결돼 있으면 원본 영상을 구글 드라이브에 올려 `영상 원본` 칸에 링크합니다.

처음 한 번은 표를 만들어야 합니다. 먼저 미리보기로 확인한 뒤 `--apply`로 만듭니다. 기존 "메타 광고 레퍼런스 모음" 페이지(`NOTION_DATABASE_ID`의 부모 페이지) 안에 "📚 A급 소재 레퍼런스" 한 페이지와 브랜드·소재 두 표가 생깁니다. 추가 보기 탭은 만들지 않으며, 연결 ID는 `.env`에 저장됩니다.

```powershell
.\.venv\Scripts\python.exe notion_references.py setup           # 미리보기 (노션에 쓰지 않음)
.\.venv\Scripts\python.exe notion_references.py setup --apply   # 실제로 만들기
```

칸 소유 규칙은 이렇습니다.

- 사용자 전용: `제작 영상 링크` → `제작 날짜` → `대표님 피드백`을 소재 표에 나란히 배치합니다. adforge는 이 칸을 만들기만 하고 값은 생성·갱신·이관 요청에서 제외합니다. 이전 이름인 `소재링크`·`편집일`도 보호합니다.
- 처음만: `제목` · `진행 여부` · `소구 포인트` · 소재 본문(광고 카피) — 처음 저장할 때만 채우고, 다시 저장할 때는 고친 값을 그대로 둡니다.
- 비어 있을 때만: `영상 원본` — 드라이브 링크를 덮어쓰지 않습니다.
- 그 밖의 칸과 브랜드 본문의 "🤖 adforge 자동 기록" 박스는 저장할 때마다 최신 값으로 바뀝니다. 박스 밖에 적은 메모는 건드리지 않습니다.

다시 탐색하면 노션 소재 표에 이미 있는 소재는 브랜드 카드와 저장 표에서 빼고 "노션에 있는 소재 N개 제외"로 표시합니다. 광고 ID·묶음 ID·영상 자산 ID 중 하나가 같거나, 같은 브랜드에서 첫 문장이 같으면 같은 소재로 봅니다(다른 브랜드가 같은 문장을 쓰면 빼지 않음). A급 판정과 순위는 제외 전 전체 광고로 계산합니다. "노션에 있는 소재도 보기"를 켜면 다시 보이고, 그 상태에서 저장하면 갱신만 합니다.

### 기존 노션 레퍼런스 옮기기

기존 기획표·검증표의 행을 지금 A급 기준으로 다시 판정해 통과한 것만 새 표로 옮깁니다. 행에서 메타 광고 ID를 찾아 지금도 60일 이상 게재 중인지 메타에서 확인하고, 브랜드명·제품명 검색량을 다시 조회합니다. 확인할 수 없는 광고는 옮기지 않고, 사람 전용 칸은 읽지도 옮기지도 않으며, 기존 행은 고치지 않습니다.

```powershell
.\.venv\Scripts\python.exe notion_migrate.py plan                         # 보고서: outputs/notion_migration/
.\.venv\Scripts\python.exe notion_migrate.py apply outputs\notion_migration\migration_plan_<시각>.json
.\.venv\Scripts\python.exe notion_migrate.py tidy                         # 기존 DB 정리 미리보기
.\.venv\Scripts\python.exe notion_migrate.py tidy --rename --apply        # 기존 DB 이름 앞에 "(보관)"
.\.venv\Scripts\python.exe notion_migrate.py tidy --trash-template --apply  # 부모 페이지 템플릿 잔여물을 휴지통으로
```

`NAVER_CUSTOMER_ID`, `NAVER_ACCESS_LICENSE`, `NAVER_SECRET_KEY`가 없으면 ①을 확인할 수 없습니다. 검색량은 아이템스카우트 데이터를 직접 가져온 값이 아니라 같은 원리로 계산한 추정치라 조금 다를 수 있습니다. 메타 광고 라이브러리와 네이버 데이터랩의 공개 웹 조회를 쓰기 때문에 요청이 몰리면 일부 검색이 실패할 수 있고, 실패한 검색은 화면에 경고로 표시합니다.

### 현재 Streamlit 앱에서 로컬 소스 자동 배치 (컷당 최대 3초)

`streamlit run app.py`를 실행하고 **캡컷 연동 및 자동 숏폼 생성** 탭에서 대본과 로컬 미디어 폴더를 입력합니다. 소스 폴더는 한 줄에 하나씩 여러 개 입력할 수 있으며, 현재 PC의 `윤라영님모델_소스`와 `샤오홍슈 소스`가 기본값입니다.

앱은 문장을 자막 한 줄 크기의 의미 단위로 나누고, 소스 하나가 3초를 넘지 않게 의미 단위를 컷으로 묶습니다. 컷마다 컷의 단어, 같은 문장과 앞뒤 문장의 흐름, 장면 역할(후킹·문제·결과·구매 유도·본문)을 함께 보고 파일명·폴더명·태그가 맞는 영상/사진을 추천합니다. LLM API 키가 있으면 **AI가 대본 전체 문맥을 읽고 컷별 소스 고르기**를 쓸 수 있습니다. 대본과 소스의 폴더·파일 이름(PC 전체 경로 제외)을 선택한 LLM에 보내 "이거 = 제품"처럼 단어에 드러나지 않는 문맥까지 반영합니다. AI 결과는 컷 구성이 바뀔 때만 다시 요청하고, 실패하면 규칙 기반 추천을 씁니다. 컷마다 추천 근거가 표시되고 소스를 직접 바꿀 수 있습니다. 근거가 전혀 없는 컷은 비워 둡니다.

컷 길이는 문장별 오디오 검수에서 미리 만든 음성이 있으면 그 실제 길이로, 없으면 발화 속도 추정치로 계산합니다. 초안을 만들 때 실제 TTS 길이로 다시 확인해 3초를 넘는 컷은 다음 추천 소스로 한 번 더 나눕니다. 영상이 컷보다 짧으면 다음 후보가 나머지를 채우고, 부족분이 작을 때만 조금 느리게 재생합니다. 같은 영상을 다시 쓰면 아직 쓰지 않은 구간부터 씁니다. 문장 안의 컷끼리는 하드컷이고 전환은 문장 경계에만 넣습니다. 생성 결과에 가장 긴 컷의 길이가 표시됩니다.

파일명만으로 장면을 알기 어려운 경우, 소스 폴더 최상위에 `assets.json`을 두고 태그를 보강할 수 있습니다.

```json
{
  "assets": {
    "clip01.mp4": {"tags": ["피부", "모공", "거울"]}
  }
}
```

현재 CapCut 초안에는 선택한 소스, TTS, 폰트를 포함한 자막이 들어갑니다. 기본 스타일은 일부 CapCut 내장 전환, 영상 효과, 문장별 자막 입장 애니메이션을 함께 배치합니다. 기존 프로젝트에서 추출한 프리셋을 선택하면 프리셋의 자막 스타일과 일부 효과·전환 적용을 시도합니다. `0928 (3)` 샘플 프로젝트가 있으면 그 안의 CapCut 내장 효과음 4종을 훅·문제·결과·구매 안내 장면에 별도 트랙으로 배치할 수 있습니다. 해당 샘플 프로젝트와 CapCut 캐시 음원 파일이 존재해야 하며, 전체 템플릿의 자동 재현은 아직 구현되지 않았습니다.

생성 직후에는 초안 JSON의 영상·음성·자막 클립과 효과 참조, 파일 경로를 검사하고 연결된 수량을 화면에 표시합니다. 이 검사는 CapCut 앱에서 실제 렌더링되는 모습까지 보증하지 않습니다.

자막 기본 위치는 CapCut 화면 좌표 `(0, -200)`입니다. 설치된 사용자 폰트 7종을 훅·본문·결과·구매 안내 폰트 선택기에 표시합니다. 기본값은 각각 양굵은구조폰트·메모먼트꾹꾹체·상상토끼 꽃집막내딸·김씨와일드각체입니다. 속초바다 돋움체를 선택하면 오른쪽으로 8° 회전합니다.

문장별 TTS 검수에서 만든 음성은 프로젝트 생성 시 해당 문장에 그대로 복사합니다. 생성 경로에서는 문장 끝을 자르지 않고, 가능하면 짧은 끝 여백을 추가한 뒤 실제 오디오 길이로 자막 시간을 계산합니다. 대본을 바꾸면 이전 검수 음성은 자동으로 해제됩니다.
